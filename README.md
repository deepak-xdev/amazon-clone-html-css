# Amazon Homepage UI Clone

A front-end clone of the Amazon homepage created using HTML and CSS.
This project focuses on replicating the layout and visual design for
practice purposes only.

## Features
- Amazon-style homepage layout
- Navigation bar and product sections
- Hover effects and basic UI interactions
- Pure HTML and CSS (no JavaScript)

## Technologies Used
- HTML5
- CSS3
